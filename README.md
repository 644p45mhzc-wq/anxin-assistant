# 安心助手

给老年人使用的中文 AI 网站，包含聊天、备忘和设置三个页面。用户可以打字或说话，核对识别文字后再发送，也可以展开和朗读回答。界面支持三档字号和高对比显示。

## 本地运行

安装 JDK 21。首次启动时，Maven Wrapper 需要联网下载依赖。要使用 DeepSeek 对话，请先在启动服务的环境中设置 `DEEPSEEK_API_KEY`。凭证配置在服务端，网页通过同一网站的账号和对话接口发起请求。

- **macOS**：在项目根目录运行 `./启动网站.command`。使用默认配置时，也可以双击该脚本启动。
- **Windows**：在 PowerShell 进入 `voice-chat-backend 3`，运行 `.\start.ps1`。
- 服务启动后，打开 [本地网站](http://localhost:8080)，注册并登录。可通过[健康检查](http://localhost:8080/api/health)查看服务状态。

## 维护入口

| 内容 | 用途 |
|---|---|
| `源代码/` | 正式网页。修改页面结构、样式或交互时，从这里开始。 |
| `voice-chat-backend 3/` | Java 后端、数据库迁移、自动化测试和 Maven 构建配置。打包时会从同级的 `源代码/` 读取网页文件。 |
| [后端维护说明](voice-chat-backend%203/README.md) | 环境变量、数据库和接口调试。启动后可查看当前版本的 [Swagger UI](http://localhost:8080/swagger-ui.html)。 |
| `安心助手.html`、`双击打开.cmd` | 离线界面预览。Windows 脚本打开单文件版；测试账号登录和 AI 对话请使用上面的本地网站。 |
| `源代码/start-server.js` | 仅提供前端静态预览。它与完整网站默认使用同一端口，分别启动即可。 |

## 备忘与提醒

登录后的备忘、账号和聊天记录保存在后端数据库，默认位置是服务工作目录下的 `data/`。同一账号在另一浏览器可以读取备忘。访客备忘保存在当前浏览器，登录后可选择导入。旧版同账号的本机备忘会自动迁移。

聊天识别出待办事项后，会请用户核对内容、时间和细节。确认保存后，页首根据备忘显示最近的提醒。提醒通过打开的网站展示；到点响铃和系统通知尚未实现。

## 测试与交付

在后端目录执行 `sh mvnw clean package`（Windows 使用 `.\mvnw.cmd clean package`）。此命令运行自动化测试，并在 `target/` 生成包含网页的可执行 JAR。2026 年 11 月 26 日，整合版通过 23 项后端测试，打包后的首页与健康检查已验证。

手动验收时可走完以下流程：

1. 注册、登录并发送问题。继续同一对话、改名，再从历史对话打开。网络中断后重试，核对消息只保存一轮。
2. 在聊天中输入“提醒我明天上午九点去社区中心”。确认后查看备忘和页首提醒，再用同账号在另一浏览器修改时间，回到原网页核对。
3. 在手机上切换三档字号和高对比，检查菜单、备忘标题栏与按钮。**真机待验收**：麦克风授权、说话转文字、手动改字、回复朗读及暂停。浏览器模拟视口已检查。
4. 部署后的验收包括服务重启后再次登录，确认聊天历史及备忘仍然可读。
