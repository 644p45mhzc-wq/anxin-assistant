# 安心助手网站

聊天、备忘和设置共用一个网站。后端负责账号认证、会话归属和 DeepSeek 调用，浏览器负责录音转写、朗读和交互。

## 本地启动

安装 Java 21 后，在 Mac 上双击「启动网站.command」。也可以在「voice-chat-backend 3」目录运行 `sh mvnw spring-boot:run`。首次启动需要联网下载构建依赖。打开 http://localhost:8080 并用测试账号注册、登录。

真实模型回复需要在启动服务的环境配置 DEEPSEEK_API_KEY。账号功能独立于模型密钥。请使用服务端环境变量保管密钥。根目录的「安心助手.html」供离线查看界面，完整体验请使用服务网址。

## 数据与打包

默认 H2 文件数据库在服务工作目录的 data 文件夹内，保存账号、凭证摘要、聊天记录与账号备忘。部署时需要持久化该目录或配置兼容数据库。登录后，手动新增与聊天确认的备忘都保存在当前账号。返回网页或打开备忘页时会同步列表与顶部提醒。旧版同账号备忘会从原浏览器自动导入。未登录时的备忘保存在本机，可在登录后进入备忘页选择导入。登录凭证保存在当前标签页的 sessionStorage，退出会调用后端注销。

从项目根目录保留「源代码」与「voice-chat-backend 3」并列结构。在后端目录运行 `sh mvnw clean package`，构建会把当前网页打进 target 下的可运行 JAR。
