# 演示与测试清单

## 推荐演示流程

1. 打开 `安心助手.html`。
2. 点击右上角“字号”，展示三档字号。
3. 在设置中打开高对比显示。
4. 返回聊天，输入一句话并发送。
5. 展开回答并点击朗读。
6. 演示暂停、继续、拖动进度和切换语速。
7. 新增一条备忘，再进行编辑、搜索和删除。
8. 新增一条提醒，再演示暂停、启用、编辑和删除。
9. 刷新页面，确认本地数据仍然存在。

## 交付前检查

- [ ] 在最新版 Chrome 或 Edge 中打开
- [ ] 字号按钮可循环切换
- [ ] 四个底部导航均可使用
- [ ] 消息可以发送，回答可以展开
- [ ] 朗读可以暂停、继续和结束
- [ ] 进度滑块和三档语速可以操作
- [ ] 备忘可以新增、编辑、搜索和删除
- [ ] 提醒可以新增、编辑、暂停、启用和删除
- [ ] 弹窗的取消、右上角关闭和 Esc 均可关闭
- [ ] 刷新后本地数据仍然存在

## 真机调研建议

- 至少邀请 3 至 5 位目标年龄段用户完成同一组任务。
- 记录是否能独立找到功能、完成任务所需时间和误操作次数。
- 不要只问“好不好用”，应观察实际操作过程。
- 重点验证字体是否足够大、按钮命名是否易懂、朗读速度是否合适。
