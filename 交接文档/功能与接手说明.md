# 功能与接手说明

## 已实现功能

### 聊天

- 打字输入和发送
- 浏览器语音转文字，识别结果可修改后发送
- 简短回答优先，详细内容可展开或收起
- 演示用本地回答逻辑

### 回答朗读

- 朗读、暂停、继续和结束
- 暂停后从当前位置继续
- 拖动文字进度滑块跳转朗读位置
- 慢速、正常、快速三档语速
- 显示当前朗读进度
- 自动朗读开关

浏览器语音接口不提供真正的音频时间轴。当前进度条按照文字位置工作，拖动后可能在相邻汉字处开始朗读。

### 备忘

- 新增、编辑和删除
- 删除前二次确认
- 关键词搜索
- 浏览器本地保存

### 提醒

- 新增、编辑和删除
- 启用或暂停提醒
- 日期时间选择
- 状态显示与浏览器本地保存

当前版本只保存提醒信息，不会在操作系统层面定时弹出通知。正式通知需要后端定时服务或 Android 原生通知能力。

### 易用性

- 标准、大、特大三档字号
- 大按钮和清晰点击区域
- 高对比显示
- 手机底部功能导航
- 键盘焦点样式

## 源码结构

- `index.html`：页面结构
- `styles.css`：页面视觉和响应式布局
- `app.js`：全部交互与本地数据逻辑
- `manifest.webmanifest`：PWA 基础配置
- `service-worker.js`：离线缓存
- `start-server.js`：不依赖第三方库的本地静态服务器

## 主要接入位置

聊天发送逻辑位于 `app.js` 的 `sendButton` 点击事件。当前通过 `mockReply(text)` 返回演示回答。接入后端时，将它替换成 `fetch('/api/chat')` 请求。

登录状态下，备忘通过 /api/memos 保存到账号数据库，页首显示其中最近的提醒。未登录时，备忘保存在本机。

## 安全注意事项

- 不要把大模型 API 密钥写入前端文件。
- 医疗相关回答不能替代诊断，应提示用户核对药品说明或咨询医生。
- 正式版需要隐私说明、数据删除机制和敏感信息保护。
- 提醒与备忘属于个人信息，应在后端进行身份校验和访问控制。
